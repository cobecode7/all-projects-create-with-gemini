# متجر إلكتروني باستخدام Go

مشروع متجر إلكتروني مُبني باستخدام لغة Go، يوفر واجهة برمجة تطبيقات RESTful لإدارة المنتجات، المستخدمين، الطلبات وعربة التسوق.

## المميزات

- إدارة المنتجات (إنشاء، عرض، تحديث، حذف)
- تسجيل المستخدمين وتسجيل الدخول
- إدارة عربة التسوق
- إدارة الطلبات
- المصادقة باستخدام JWT
- التحكم في الوصول القائم على الأدوار (RBAC)
- واجهة برمجة تطبيقات RESTful

## التقنيات المستخدمة

- Go (Golang)
- Chi Router
- GORM
- PostgreSQL
- JWT للمصادقة

## المتطلبات

- Go 1.21 أو أحدث
- PostgreSQL

## التثبيت والتشغيل

1. استنساخ المستودع:
```bash
git clone <repository-url>
cd go-ar-py
```

2. تثبيت التبعيات:
```bash
go mod download
```

3. إعداد قاعدة البيانات:
```bash
# إنشاء قاعدة بيانات PostgreSQL
createdb ecommerce_db
```

4. إعداد متغيرات البيئة:
```bash
cp .env.example .env
# قم بتعديل متغيرات البيئة في ملف .env حسب الحاجة
```

5. تشغيل المشروع:
```bash
go run main.go
```

## واجهة برمجة التطبيقات (API)

### المنتجات

- `GET /api/v1/products` - عرض جميع المنتجات
- `GET /api/v1/products/{id}` - عرض منتج محدد
- `POST /api/v1/products` - إنشاء منتج جديد (يتطلب صلاحيات المشرف)
- `PUT /api/v1/products/{id}` - تحديث منتج (يتطلب صلاحيات المشرف)
- `DELETE /api/v1/products/{id}` - حذف منتج (يتطلب صلاحيات المشرف)

### المستخدمون

- `POST /api/v1/users/register` - تسجيل مستخدم جديد
- `POST /api/v1/users/login` - تسجيل الدخول
- `GET /api/v1/users/profile` - عرض معلومات المستخدم (يتطلب المصادقة)

### عربة التسوق

- `GET /api/v1/cart` - عرض محتويات عربة التسوق (يتطلب المصادقة)
- `POST /api/v1/cart` - إضافة منتج إلى عربة التسوق (يتطلب المصادقة)
- `PUT /api/v1/cart` - تحديث كمية منتج في عربة التسوق (يتطلب المصادقة)
- `DELETE /api/v1/cart` - حذف منتج من عربة التسوق (يتطلب المصادقة)
- `DELETE /api/v1/cart/clear` - تفريغ عربة التسوق (يتطلب المصادقة)

### الطلبات

- `GET /api/v1/orders` - عرض قائمة الطلبات (يتطلب المصادقة)
- `POST /api/v1/orders` - إنشاء طلب جديد (يتطلب المصادقة)
- `GET /api/v1/orders/{id}` - عرض تفاصيل طلب محدد (يتطلب المصادقة)
- `PUT /api/v1/orders/{id}/status` - تحديث حالة الطلب (يتطلب صلاحيات المشرف)
