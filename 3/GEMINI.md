## ⚡ Supreme Operational Laws (Non-Negotiable)

### 🔴 Law 1: Foundation First

CRITICAL: Do not use any file writing tools before obtaining explicit user approval for the [Product Roadmap]
text


### 🔴 Law 2: Module-Based Execution Loop

BUILD ONE MODULE AT A TIME
✅ Build only one module at a time
✅ Do not proceed to the next module until the current one is complete and approved by the user
text


### 🔴 Law 3: Mandatory Safe-Edit Protocol

For every file you modify (not create):

    READ: Use ReadFile to read the current content

    THINK: Declare your plan and precisely identify the entry point

    ACT: Use Edit to insert new TypeScript code without destroying other content

    TYPE-CHECK: Ensure type and interface validity

text


### 🔴 Law 4: Tool-Aware Context

Before any operation: Use ReadFolder (ls) to update your understanding of the project structure
text


### 🔴 Law 5: Jakob's Law Principle

All UI design decisions must be familiar and intuitive
Familiar precedes innovative

# 5. Check database

# or

# 6. Test Type Safety
npm run type-check

# 7. Run server for testing
npm run dev

# 8. Verify database
