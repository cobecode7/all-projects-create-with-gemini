# Gemini Project

تطبيق ويب مبني باستخدام Go/Gin Framework مع نظام تسجيل مستخدمين كامل.

## المميزات

- تسجيل مستخدمين جديدين
- تسجيل الدخول والخروج الآمن
- تخزين كلمات المرور المشفرة باستخدام bcrypt
- إدارة الجلسات
- واجهة مستخدم متجاوبة وجذابة

## المتطلبات

- Go 1.21 أو أحدث
- PostgreSQL قاعدة بيانات

## التثبيت والتشغيل

1. استنساخ المستودع:
   ```
   git clone <repository-url>
   cd gemini-project
   ```

2. تثبيت الاعتماديات:
   ```
   go mod download
   ```

3. إعداد قاعدة البيانات:
   - أنشئ قاعدة بيانات PostgreSQL باسم `gemini`
   - عدّل ملف `.env` ليتناسب مع إعدادات قاعدة البيانات الخاصة بك

4. تشغيل التطبيق:
   ```
   go run main.go
   ```

5. افتح المتصفح على العنوان: `http://localhost:8080`

## هيكل المشروع

```
gemini-project/
```
